# ADS 2026 - PROJEÇÃO

> ⚠️ **UM REPOSITÓRIO NOVO SURGIRÁ AO FIM DE CADA SEMESTRE**

---

## Objetivo do Repositório

Este repositório tem como finalidade centralizar e disponibilizar os conteúdos, materiais e anotações referentes às disciplinas do primeiro semestre de 2026 do curso de ADS.

O projeto foi criado com o objetivo de auxiliar estudantes que, por diferentes motivos, perderam aulas, ficaram temporariamente sem acesso ao computador utilizado anteriormente ou necessitam recuperar conteúdos acadêmicos de forma organizada e acessível.

Além disso, o repositório busca servir como um ponto de apoio para consultas rápidas, revisão de matérias e acompanhamento complementar das disciplinas ao longo do semestre.
