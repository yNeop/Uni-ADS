## 01
### O que é UML?

Uma linguagem padronizada para modelagem de software, criada nos anos 90 por Booch, Jacobson<br>
e Rumbaugh com o proposito de auxilia no desenvolvimento.<br>

## 02
### Quando usar cada Diagrama

| Situação                                                               | Diagrama mais adequado                       |
| ---------------------------------------------------------------------- | -------------------------------------------- |
| Levantar funcionalidades que o usuário espera do sistema               | Diagrama de Casos de Uso                     |
| Mostrar interação entre usuário e sistema                              | Diagrama de Casos de Uso                     |
| Modelar estrutura do sistema (classes, atributos, métodos)             | Diagrama de Classes                          |
| Mostrar objetos existentes em um momento específico                    | Diagrama de Objetos                          |
| Representar fluxo de um processo ou algoritmo                          | Diagrama de Atividades                       |
| Representar fluxo de processo dividido por responsáveis/setores/atores | Diagrama de Atividades com Swimlanes (Raias) |
| Mostrar componentes físicos ou módulos do sistema                      | Diagrama de Componentes                      |
| Mostrar troca de mensagens ao longo do tempo                           | Diagrama de Sequência                        |
| Mostrar comunicação entre objetos enfatizando relacionamentos          | Diagrama de Comunicação                      |
| Representar estados de um objeto e suas transições                     | Diagrama de Estados                          |
| Mostrar infraestrutura e onde o software será executado                | Diagrama de Implantação                      |
| Modelar estrutura hierárquica de pacotes                               | Diagrama de Pacotes                          |
