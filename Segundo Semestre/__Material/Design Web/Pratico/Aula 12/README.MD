# Trabalho Prático - 2 pontos 
Composição: individual ou em dupla.

Elabore um site sobre um assunto do seu interesse (viagens, séries, filmes, produtos...)
O site precisa ter uma paleta de cores bem definida, itens bem formatados e completos. 
Entrega no blog da disciplina até o final da aula em uma única entrega (zipado). 

Itens Obrigatórios: 

- Menu 
- Lista
- Formulário
- Imagens
- Html Semântico
- Mínimo 3 páginas
- Card

Itens avaliados:

- Formatações 
- Cores 
- Itens Obrigatórios 
- Criatividade
