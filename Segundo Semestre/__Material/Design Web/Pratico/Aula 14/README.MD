# Trabalho Prático - 2 pontos 
Entrega: dia  22/06 aqui nesta postagem.

Composição: Individual ou dupla

Criar uma página web utilizando Bootstrap.
Selecionar uma área de negócio da sua escolha e desenvolver uma página utilizando componentes Bootstrap. 

A página deve conter no mínimo 5 componentes do Bootstrap. 

Componentes obrigatórios: Carousel, Grid, Nav e Cards + um componente livre. 

Trabalhos identificados como cópia receberão nota igual a zero.

Critérios de Avaliação:

- Criatividade 
- Cores 
- Utilização de componentes obrigatórios 
- Organização da página
